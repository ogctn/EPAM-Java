# JPA Playground Project

Use this project to learn and experiment with JPA and Hibernate.


## Current Project

It already contains a few entities to demonstrate the following:
- Create and query object(s)
- Bidirectional relationship
  - Update relation on both side
  - Circular reference
- Lazy loading
- Cascade operations

You can play with this application.

The H2 database console is accessible at the following URL: [http://localhost:8080/h2-console](http://localhost:8080/h2-console)


## Next Steps

You can practice the following JPA features:
- Mapping special types: enum, date and time, embedded
- Many-to-many relationship
- Inheritance mapping
- Transaction: make related operations atomic (e.g. transfer money between accounts)
- Query: aggregates
- Lifecycle, Entity Listeners
